# 盆底治疗仪蓝牙通讯协议 V1.1.9

## 1. 使用说明

蓝牙模块与设备之间为透明串口，串口参数为 **115200，8 数据位，1 停止位，无校验、无流控**。

- 协议版本固定为 `0x11`。
- 设备连接后，小程序发送的合法协议帧默认可控制设备。
- 所有多字节整数使用**小端序**。
- BLE 物理连接建立后，设备每 1 s 主动发送一次完整状态。

## 2. 帧格式

```text
Byte 0..1  Byte 2  Byte 3  Byte 4  Byte 5..(4+LEN)  最后 1 字节
5A A5      VER     LEN     CMD     DATA[LEN]         CRC8
```

总帧长为 `6 + LEN` 字节；当 `LEN=0` 时不包含 DATA 字段。


| 字段  | 长度 | 说明                                       |
| ----- | ---: | ------------------------------------------ |
| FRAME |    2 | 固定`5A A5`                                |
| VER   |    1 | 固定`11`                                   |
| LEN   |    1 | DATA 字节数，范围`0..32`；不含 CMD 和 CRC8 |
| CMD   |    1 | 命令码                                     |
| DATA  |    N | 命令数据                                   |
| CRC8  |    1 | CRC-8/ATM，覆盖从`5A` 到 DATA 最后一个字节 |

协议采用串行请求/响应方式，同一时刻最多允许一条请求等待响应，**不使用事务序号（SEQ）字段**。主机以当前唯一在途请求和响应中的 `REQ_CMD` 关联应答；主动通知通过独立命令码区分。

## 3. CRC-8/ATM


| 参数          | 值                                          |
| ------------- | ------------------------------------------- |
| 多项式        | `0x07`                                      |
| 初值          | `0x00`                                      |
| 输入/输出反射 | 否                                          |
| 结果异或值    | `0x00`                                      |
| 计算范围      | `FRAME + VER + LEN + CMD + DATA`，不含 CRC8 |

查表计算公式：

```text
crc = 0x00
for each byte b in data:
    crc = table[(crc XOR (b AND 0xFF)) AND 0xFF]
```

## 4. 请求与响应

设备收到每个合法请求后，应在 200 ms 内回应。设备统一使用 `CMD=E0` 响应：

```text
响应 DATA = REQ_CMD(1) + RESULT(1) + RESPONSE_DATA(N)
```

例如，查询状态成功响应的帧结构为：

```text
5A A5 11 18 E0 71 00 [22 字节状态快照] CRC8
```

主机必须等待 `RESPONSE` 后再发送下一条请求。`GET_STATUS`、`LINK_KEEPALIVE`、`STOP_ALL` 以及绝对设定类 `MODE_CONTROL` 在 200 ms 未收到响应时，允许重发**完全相同**的原帧，最多重试 2 次。`START_SESSION`、`STOP_SESSION`、模式切换及 `POWER_OFF` 不携带事务序号，响应超时后不得自动重发；主机应改发 `GET_STATUS` 恢复设备实际状态。

`RESULT=OK` 是设备对当前请求的 ACK：同步设置已生效，异步动作已通过检查并被受理；异步动作的后续状态以通知或 `GET_STATUS` 为准。心跳只用于链路存活和远程危险动作超时保护，不替代命令 ACK。无 SEQ 的串行模型不能证明主机一定收到了 ACK，不能据此把未收到响应的命令判定为未执行。

- CRC、版本或长度错误：设备不响应。
- 未知命令：设备响应 `UNSUPPORTED`。
- 重复的查询、心跳和安全停止命令：返回当前结果，不产生附加动作。
- `START_SESSION`、`STOP_SESSION`、模式切换或 `POWER_OFF` 响应丢失：不得自动重发相同动作，应查询状态后由用户决定是否再次操作。

### 4.1 结果码


| 值   | 名称           | 含义                       |
| ---- | -------------- | -------------------------- |
| `00` | OK             | 操作成功或请求已受理       |
| `01` | BAD_LENGTH     | DATA 长度错误              |
| `02` | BAD_PARAMETER  | 参数范围或枚举值错误       |
| `03` | UNSUPPORTED    | 当前固件不支持该命令       |
| `04` | STATE_CONFLICT | 当前设备状态不允许执行     |
| `05` | CHARGING_LOCK  | 充电互锁，禁止执行危险操作 |
| `06` | SAFETY_LOCK    | 设备安全条件不满足         |
| `08` | BUSY           | 设备正在处理不可并行的动作 |
| `09` | INTERNAL_ERROR | 设备内部错误               |

## 5. 命令定义


| CMD  | 名称           | 请求 DATA                           | 设备限制                                                       |
| ---- | -------------- | ----------------------------------- | -------------------------------------------------------------- |
| `02` | MODE_CONTROL   | `mode:u8 + action:u8 + action_data` | 治疗与压力模式业务控制；限制见 5.1                             |
| `03` | LOCAL_KEY_LOCK | `lock:u8`                           | 锁定或释放本地物理按键；限制见 5.2                             |
| `08` | STOP_ALL       | 空                                  | 任意状态允许；治疗输出和气泵关闭，气阀进入经硬件确认的安全状态 |
| `09` | POWER_OFF      | 空                                  | 独立关机命令；仅治疗或压力模式允许，限制见 5.3                 |
| `71` | GET_STATUS     | 空                                  | 任意状态允许                                                   |
| `90` | LINK_KEEPALIVE | 空                                  | 兼容旧版；设备应答，但小程序无须周期发送                       |

当前固件已补齐物理连接检测、远程危险动作来源和断链安全关断框架。小程序使用绝对参数控制业务，不再模拟本地按键短按、长按或加减档。远程关机、治疗与压力动作的编译开关当前均已开启；可能增加治疗输出或启动压力执行器的动作仍受工作状态、充电互锁和 PB7 物理连接检查约束。

`01`、`04..07` 与 `10` 在本版中保留，收到后返回 `UNSUPPORTED`。治疗和压力业务统一使用 `MODE_CONTROL (02)`，关机使用独立 `POWER_OFF (09)`。

本节定义的 `MODE_CONTROL`、压力会话通知及实时压力通知由本固件版本实现；小程序须与本协议同步适配。除 `GET_STATUS` 外，命令响应仅表示受理结果；当前状态以每秒 `STATUS_NOTIFY` 或显式 `GET_STATUS` 为准。

### 5.1 MODE_CONTROL

`MODE_CONTROL` 的 DATA 统一为 `mode:u8 + action:u8 + action_data`，全部参数均为绝对值，不模拟本地按键。`mode` 必须与当前设备模式一致；治疗模式收到压力业务命令、压力模式收到治疗业务命令时均返回 `STATE_CONFLICT`。模式切换只能使用当前模式中定义的切换 action。


| mode | 名称     | action | 名称                   | action_data       | 说明                                  |
| ---: | -------- | -----: | ---------------------- | ----------------- | ------------------------------------- |
| `01` | THERAPY  |   `01` | SET_STRENGTH           | `level:u8`        | 设定当前选中治疗通道强度，范围`0..60` |
| `01` | THERAPY  |   `02` | SET_DURATION           | `minutes:u8`      | 设定疗程时间，仅允许`10/20/30`        |
| `01` | THERAPY  |   `03` | SET_PROFILE            | `profile:u8`      | 设定`P1/P2/P3`，取值`1..3`            |
| `01` | THERAPY  |   `04` | SELECT_CHANNEL         | `channel:u8`      | 选择`CH1/CH2`，取值`1..2`             |
| `01` | THERAPY  |   `05` | STOP_THERAPY           | 无                | 停止治疗并将两路强度清零              |
| `01` | THERAPY  |   `06` | SWITCH_TO_PRESSURE     | 无                | 安全停止治疗并切换到压力模式          |
| `02` | PRESSURE |   `01` | SET_TARGET_AND_INFLATE | `target_mmhg:u16` | 设定目标压力并立即启动充气            |
| `02` | PRESSURE |   `02` | START_SESSION          | `duration_s:u16`  | 在等待测试状态开始测试或训练会话      |
| `02` | PRESSURE |   `03` | STOP_SESSION           | 无                | 结束正在进行的测试或训练会话          |
| `02` | PRESSURE |   `04` | DEFLATE                | 无                | 开始放气；放气完成后清空本轮数据      |
| `02` | PRESSURE |   `05` | STOP_INFLATE           | 无                | 仅在充气阶段停止充气并复位流程        |
| `02` | PRESSURE |   `06` | SWITCH_TO_THERAPY      | 无                | 安全停止压力流程并切换到治疗模式      |

所有成功执行的 `MODE_CONTROL` 命令均响一声，并仅返回 `REQ_CMD + OK`。参数、状态或安全门禁检查失败时不响；当前状态由 `STATUS_NOTIFY` 或 `GET_STATUS` 获取。

#### 5.1.1 THERAPY / SET_STRENGTH

请求 DATA 固定为 3 字节：`01 01 level`。`level` 为当前选中治疗通道的目标强度，范围 `0..60`；当前选中通道可通过 `SELECT_CHANNEL` 绝对设定，并通过状态快照的 `selected_channel` 字段确认。

- 强度从 `0` 变为非零时，仍须执行治疗启动、充电互锁、BLE 物理连接和安全条件检查；检查不通过时不得改变强度或输出。
- `level=0` 仅将当前选中通道强度清零；当两通道均为 0 时，必须执行治疗输出安全关断路径。

#### 5.1.2 THERAPY 其他操作

- `SET_DURATION`：请求为 `01 02 minutes`，成功后同时重置配置时长和剩余时长。
- `SET_PROFILE`：请求为 `01 03 profile`；切换到不同 P 模式前统一停止治疗并清零两路强度。
- `SELECT_CHANNEL`：请求为 `01 04 channel`，使用 `1=CH1`、`2=CH2`。
- `STOP_THERAPY`：请求为 `01 05`，立即执行治疗统一安全关断并结束当前会话。
- `SWITCH_TO_PRESSURE`：请求为 `01 06`，仅治疗模式允许；切换前执行治疗统一安全关断。

#### 5.1.3 PRESSURE / SET_TARGET_AND_INFLATE

请求 DATA 固定为 4 字节：`02 01 target_low target_high`。`target_mmhg` 为小端序 `u16`，合法范围为 `1..PRESSURE_MAX_MMHG-1`；`PRESSURE_MAX_MMHG` 由设备编译宏决定，协议中不固定具体数值。

- `target_mmhg=0` 或 `target_mmhg>=PRESSURE_MAX_MMHG` 时返回 `BAD_PARAMETER`。
- 当前压力大于或等于 `target_mmhg`，或已触发最大压力锁定而尚未放气时，返回 `SAFETY_LOCK`（小程序显示 `006`），不启动气泵。
- 命令受理并启动气泵时，重新开始 60 s 充气超时计时；达到目标后停止气泵，进入等待测试状态。
- 连续充气满 60 s 时停止气泵并保持非闪烁压力显示；可再次发送本命令重新开始 60 s 充气，最大压力锁定状态除外。
- 本地短按在空闲状态时按 `PRESSURE_HALF_INFLATE_MMHG` 作为默认目标启动充气；充气过程中短按可停止气泵；在等待测试状态再次短按可启动正式会话；本地长按或 `DEFLATE` 会执行放气并清空本轮流程。
- 目标可直接使用半充盈和全充盈宏对应的值，也允许小程序发送其他合法目标压力。

#### 5.1.4 PRESSURE / START_SESSION

请求 DATA 固定为 4 字节：`02 02 duration_low duration_high`。`duration_s` 为小端序 `u16`，允许范围为 `1..1800 s`。

- 仅在已达到目标且气泵停止的等待测试状态允许；受理后立即确认气泵关闭。
- 测试和训练使用同一设备流程；差异仅由小程序引导内容和 `duration_s` 决定。
- 会话期间 ADC2 按 20 Hz 持续采集压力；ADC1 的电池/参考采样调整为每 10 s 一次。

#### 5.1.5 PRESSURE / 停止、放气与模式切换

`STOP_SESSION` 请求 DATA 为 `02 03`，仅正式会话状态允许；结束计时和数据累计，计算平均压力，停止闪烁并进入结果保持状态。

结果保持状态禁止再次充气或开始会话，仅允许 `DEFLATE`。`DEFLATE` 请求 DATA 为 `02 04`，压力模式任意子状态允许；放气完成或放气超时后清除本轮测试数据、平均值和计时状态，返回空闲状态。

`STOP_INFLATE` 请求 DATA 为 `02 05`，仅充气阶段允许；停止气泵并复位本轮压力流程。`SWITCH_TO_THERAPY` 请求 DATA 为 `02 06`，仅压力模式允许；切换前停止气泵、阀门及当前压力会话。

#### 5.1.6 压力流程状态与结果码

压力子状态依次为：空闲、充气中、等待测试、正式会话、结果保持和放气。空闲状态压力值正常显示，不闪烁，且本轮累计值、样本数、平均值和计时状态均为空。


| 条件                                     | 命令响应             | 设备动作                 |
| ---------------------------------------- | -------------------- | ------------------------ |
| 目标压力为 0 或不小于`PRESSURE_MAX_MMHG` | `002 BAD_PARAMETER`  | 不改变流程或执行器状态   |
| 当前压力已达到请求目标                   | `006 SAFETY_LOCK`    | 不启动气泵；应先放气     |
| 达到最大安全压力后请求充气               | `006 SAFETY_LOCK`    | 保持气泵关闭，仅允许放气 |
| 结果保持状态请求充气或开始会话           | `004 STATE_CONFLICT` | 保持结果，拒绝请求       |
| 充电互锁或物理连接门禁不满足             | 既有`005` 或 `006`   | 不启动危险输出           |

### 5.2 LOCAL_KEY_LOCK

`LOCAL_KEY_LOCK` 是不区分治疗/压力页面的全局命令。请求 DATA 长度固定为 1：


| DATA[0] | 名称    | 行为                             |
| ------: | ------- | -------------------------------- |
|    `00` | RELEASE | 释放本地按键锁，恢复本地按键功能 |
|    `01` | LOCK    | 锁定本地按键功能                 |

- 锁定后，设备忽略全部**物理**按键的短按、长按及其对应业务事件；小程序通过 BLE 发送的 `MODE_CONTROL`、`POWER_OFF`、`STOP_ALL` 等命令不受影响。
- 物理电源键长按关机始终不受按键锁影响，仍走既有统一安全关断路径。
- 按键锁仅保存在 RAM：BLE 物理断链、协议复位、系统复位或重新上电后自动释放，避免断链后无法进行本地控制。
- 成功响应仅返回 `REQ_CMD + OK`；本地按键锁定状态通过后续 `STATUS_NOTIFY` 或 `GET_STATUS` 的 `flags.bit7` 获取。

### 5.3 POWER_OFF

`POWER_OFF (CMD=09)` 请求 DATA 为空，仅在治疗或压力模式允许。设备先响一声并立即关闭治疗、气泵和阀门等危险输出，仅返回 `REQ_CMD + OK`；为保证响应完整发出，设备至少保留 20 ms 通讯窗口且确认协议 TX 队列排空后，再进入 `POWER_OFF`，有充电接入时进入 `CHARGING`。

关机请求等待期间再次发送 `POWER_OFF` 返回 `BUSY`。远程开机不支持，因为关机状态会关闭蓝牙模块。

### 5.4 主动通知


| CMD  | 名称                        | 说明                                               |
| ---- | --------------------------- | -------------------------------------------------- |
| `91` | STATUS_NOTIFY               | BLE 连接后由设备每 1 s 发送一次完整状态            |
| `93` | PRESSURE_SESSION_END_NOTIFY | 每次压力会话结束时发送结束原因和统计结果           |
| `95` | PRESSURE_SAMPLE_NOTIFY      | 正式压力会话中以 20 Hz 发送实时压力值              |
| `94` | THERAPY_END_NOTIFY          | 治疗结束后发送结束类型、通道、模式、时长和两路强度 |

通知帧无须回应。

#### 5.4.1 THERAPY_END_NOTIFY（`CMD=94`）

设备不发送治疗开始通知。治疗会话因疗程倒计时结束或主动结束而关闭全部输出后，按以下规则发送一次结束通知：

- 计时结束：始终发送，`duration_seconds` 固定为当前疗程配置对应的 `600`、`1200` 或 `1800` s。
- 主动结束：包括切换脉冲模式、切换至压力检测模式、关机、`STOP_ALL` 及远程危险动作超时等。均发送，`duration_seconds` 为累计有效输出时间向下换算的完整秒数。
- 两通道强度均为 `0` 仅暂停输出和有效时间累计，不结束会话，也不发送通知。
- BLE 已断开或模块关闭时无法发送通知；通知发送失败不得阻塞或延迟安全关断。

`DATA` 长度固定为 7。`channel_mask` 表示本次会话内实际曾输出过的通道，而不是仅表示结束瞬间的强度。强度字段为统一安全关断清零前的 UI 档位，不是 DAC 码值。


| 偏移 | 长度 | 字段             | 定义                                                             |
| ---: | ---: | ---------------- | ---------------------------------------------------------------- |
|    0 |    1 | end_type         | `0=计时结束`，`1=主动结束`                                       |
|    1 |    1 | channel_mask     | `0x01=CH1`，`0x02=CH2`，`0x03=CH1+CH2`                           |
|    2 |    1 | pulse_mode       | `1=P1`，`2=P2`，`3=P3`                                           |
|    3 |    2 | duration_seconds | `u16` 小端序，单位 s；主动结束以累计有效输出毫秒数向下换算完整秒 |
|    5 |    1 | ch1_level        | CH1 结束时强度，`0..60`；无强度时为 `0`                          |
|    6 |    1 | ch2_level        | CH2 结束时强度，`0..60`；无强度时为 `0`                          |

#### 5.4.2 PRESSURE_SESSION_END_NOTIFY（`CMD=93`）

每次正式测试或训练会话结束后发送一次。`DATA` 长度固定为 8，多字节字段均为小端序。


| 偏移 | 长度 | 字段                  | 定义                                                                                                                            |
| ---: | ---: | --------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
|    0 |    1 | end_reason            | `0=小程序停止`，`1=本地按键停止`，`2=会话时长到达`，`3=最大压力保护`，`4=切换至治疗模式`，`5=放气终止`，`6=压力 ADC/传感器异常` |
|    1 |    1 | result_valid          | `0=统计结果无效`，`1=平均压力和样本数有效`                                                                                      |
|    2 |    2 | duration_seconds      | 实际会话时长，单位 s，不足 1 s 部分舍去                                                                                         |
|    4 |    2 | average_pressure_mmhg | 平均压力，单位`1 mmHg/LSB`；无效时为 `FFFF`                                                                                     |
|    6 |    2 | sample_count          | 有效压力样本数；无效时为`0`                                                                                                     |

小程序停止、本地按键停止、时长到达、最大压力保护、放气、切换治疗模式及压力采样异常均发送本通知。最大安全压力由 `PRESSURE_MAX_MMHG` 宏决定；达到该阈值时必须优先停止气泵、结束会话并锁定充气，直至放气完成。通知发送失败不得阻塞安全停止。

#### 5.4.3 PRESSURE_SAMPLE_NOTIFY（`CMD=95`）

正式测试或训练会话中，设备按 20 Hz 发送本通知。`DATA` 长度固定为 1：


| 偏移 | 长度 | 字段          | 定义                                                    |
| ---: | ---: | ------------- | ------------------------------------------------------- |
|    0 |    1 | pressure_mmhg | 实时压力，单位`1 mmHg/LSB`，范围 `0..PRESSURE_MAX_MMHG` |

`PRESSURE_MAX_MMHG` 必须不大于 `255`，以满足单字节实时压力值编码。若后续需要超过该范围，必须升级该通知载荷，不能静默截断。

## 7. 设备端通讯行为

1. 设备收到 `GET_STATUS` 后返回当前完整状态快照。
2. PB7 经过去抖确认 BLE 已连接后，设备每 1 s 主动发送 `STATUS_NOTIFY`，负载为当前 22 字节完整状态快照；通知无须小程序应答。
3. 设备收到 `LINK_KEEPALIVE` 后仍返回响应，用于兼容旧版小程序，但不再依赖该命令维持远程控制。
4. 设备收到 `MODE_CONTROL`、`LOCAL_KEY_LOCK` 或 `POWER_OFF` 后，先检查帧、参数、当前状态、编译门禁、充电状态和物理连接；成功控制命令响一声并仅返回 ACK，当前状态通过每秒 `STATUS_NOTIFY` 或 `GET_STATUS` 获取。未通过检查的命令不得改变设备状态、输出或触发蜂鸣。
5. PB7 确认断开或协议复位时，远程启动的危险输出调用统一安全关断；本机疗程倒计时独立运行，不依赖小程序应答或入站心跳。
6. AT 初始化异常时固件最多重试 3 次；重试后若当前 RAM 已缓存由合法 MAC 生成的目标名称，则跳过配名并进入透传。冷启动且没有缓存名称时不启用协议。
7. 物理连接状态由 KT6368A STA（PB7，高有效、外部 10 kΩ 下拉）判定并经过 100 ms 去抖；协议链路已活动但 STA 仍为低时，固件记录一次错误并复位协议状态。
8. 治疗会话开始时不发送通知。疗程倒计时结束时先快照两路结束强度、完成输出安全关断，再发送一次携带计时结束类型、会话内实际输出通道、脉冲模式、配置时长和 CH1/CH2 强度的 `THERAPY_END_NOTIFY`；主动结束均发送，并上报累计有效输出时间向下换算的完整秒数。通知发送失败不应阻塞或延迟安全关断。
9. 压力正式会话最长由小程序在 `START_SESSION` 中设置，设备限制为不超过 1800 s。会话中 ADC2 每 50 ms 采样一次并累计平均值，ADC1 电池/参考采样每 10 s 一次；设备每秒发送 20 次单字节 `PRESSURE_SAMPLE_NOTIFY`。任何结束路径均发送一次 `PRESSURE_SESSION_END_NOTIFY`；发送失败不影响安全停止。
10. 在充气、等待测试或正式会话期间，任一有效压力采样达到 `PRESSURE_MAX_MMHG` 时，最大压力保护优先于其他流程：立即停止气泵；若正在正式会话则结束会话；禁止再次充气，直至放气完成。
11. 从压力模式切换到治疗模式时，设备立即停止气泵，发送 `PRESSURE_SESSION_END_NOTIFY(end_reason=4)`，清除目标压力、累计值、样本数、平均值、计时和闪烁状态；不自动执行放气。
12. 本地按键锁定时，仅物理电源键长按关机继续有效；其余物理按键不产生业务事件。BLE 物理断链、协议复位、系统复位或重新上电时自动释放按键锁。

### 查询状态

```text
请求：5A A5 11 00 71 0F
```

### 将疗程时间设为 20 分钟

```text
请求 DATA：01 02 14
          |  |  └─ minutes=20
          |  └──── SET_DURATION
          └─────── THERAPY

CMD：02（MODE_CONTROL）
```

### 选择 CH2

```text
请求 DATA：01 04 02
CMD：02（MODE_CONTROL）
```

### 将当前选中通道的强度设为 30

```text
请求 DATA：01 01 1E
          |  |  └─ level=30
          |  └──── SET_STRENGTH
          └─────── THERAPY

CMD：02（MODE_CONTROL）
```

### 设定 36 mmHg 并启动充气

```text
请求 DATA：02 01 24 00
          |  |  └──── target_mmhg=36，小端序
          |  └─────── SET_TARGET_AND_INFLATE
          └────────── PRESSURE

CMD：02（MODE_CONTROL）
```

### 开始 30 分钟压力会话

```text
请求 DATA：02 02 08 07
          |  |  └──── duration_s=1800，小端序
          |  └─────── START_SESSION
          └────────── PRESSURE

CMD：02（MODE_CONTROL）
```

### 锁定本地按键

```text
请求 DATA：01
CMD：03（LOCAL_KEY_LOCK）
```

释放本地按键锁时，请求 DATA 为 `00`。

### 查询状态成功响应结构

示例状态：治疗模式、P2、当前选中 CH1、CH1=10、CH2=0、已配置 30 min、剩余 20:00、压力空闲、电池 80%、链路有效且 CH1 输出使能、无故障。

```text
5A A5 11 18 E0 71 00 [22 字节状态快照] CRC8
```

其中 `LEN=18`（24 字节 DATA：`REQ_CMD + RESULT + 22 字节状态快照`）。默认 ATT MTU 为 23 时该响应会分片，接收方必须按帧头、`LEN` 和 CRC8 缓存组帧。

## 9. BLE 承载参数

当前板载蓝牙芯片为 KT6368A，采用以下默认 BLE 透传参数：

- Service UUID：`0000FFF0-0000-1000-8000-00805F9B34FB`；
- 写特征 UUID：`0000FFF3-0000-1000-8000-00805F9B34FB`；
- Notify 特征 UUID：`0000FFF1-0000-1000-8000-00805F9B34FB`；
- 写入方式：`Write Without Response`；
- 默认 ATT MTU 为 23 字节，兼容性安全载荷上限为每包 20 字节；
- 设备名称：`qw316_` 加完整 12 位 BLE 地址。`AT+TN` 返回值按字节逆序转换为手机扫描器显示的 MAC 顺序，例如返回 `TN+12345678AABB` 时名称为 `qw316_BBAA78563412`。

设备启动蓝牙时先查询 BLE 地址和当前名称，仅在名称不一致时写入新名称并复位 KT6368A，避免重复写入其非易失配置。App 扫描时应同时校验 `FFF0` 服务，不得仅凭设备名称建立信任关系。

BLE 写入或通知可能拆分一帧，也可能一次携带多帧。接收方必须使用缓存按帧头和 `LEN` 组帧，不能假设一次 BLE 回调就是一帧。

### 9.1 当前连接状态判定

KT6368A 的 STA 连接状态脚接至 MCU PB7，高电平表示 BLE 已连接，未连接时由外部 10 kΩ 电阻下拉为低电平。固件对 PB7 连续采样 100 ms 后更新 UI 连接状态；模块使能后的前 1.5 s 还会检查是否出现约 1 s 的上电高脉冲，未出现时每次使能周期只记录一次错误。

收到 CRC、版本和长度均合法的协议帧后，固件另行标记“应用协议链路活动”。若协议链路活动但 PB7 仍稳定为低，固件记录一次状态不一致错误并复位协议链路；危险动作的断链保护以 PB7 物理连接和协议复位为准，不再依赖小程序周期心跳。
