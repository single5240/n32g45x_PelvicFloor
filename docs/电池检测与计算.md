# QW-316 电池检测与计算

## 1. 硬件信号

- `PA3/BATT`：电池电压经过 1/2 分压后的 ADC 输入。
- `PA6/REF`：外部 2.5 V 精密参考的 ADC 输入。
- `PB2/BATEN`：电池检测分压电路使能，高电平有效。

只在采样前打开 `BATEN`，等待 100 ms 让分压节点稳定；读取完成后立即关闭，以减少检测电路的静态耗电。

## 2. 电压计算

两个通道使用相同的 ADC 满量程和 MCU 模拟电源：

```text
ADC_BATT = (Vbat / 2) / VDDA × ADC_FULL_SCALE
ADC_REF  = 2.5 V / VDDA × ADC_FULL_SCALE
```

两式相除后，`VDDA` 和 `ADC_FULL_SCALE` 被约掉：

```text
Vbat(mV) = ADC_BATT × 2500 × 2 ÷ ADC_REF
```

代码全程使用 32 位整数，并在除法前加上半个除数实现四舍五入，不依赖浮点库。

例如平均采样值为 `ADC_BATT=2500`、`ADC_REF=3050`：

```text
Vbat = 2500 × 2500 × 2 ÷ 3050
     ≈ 4098 mV
     ≈ 4.098 V
```

## 3. 滤波过程

每轮依次读取 8 组 BATT 和 REF：

1. 每个通道分别删除一个最大值和一个最小值。
2. 对剩余 6 个值求平均。
3. 用平均值计算本轮电池电压。
4. 第一轮直接采用测量值；后续使用 `滤波值=(旧值×3+新值)/4`。

前两步过滤单次尖峰，第四步降低气泵或治疗输出造成的瞬时压降对图标的影响。

## 4. 电量显示和低电判断

| 滤波电压 | 电池显示 |
| --- | --- |
| `>= 4.10 V` | 3 格 |
| `3.90～4.10 V` | 2 格 |
| `3.70～3.90 V` | 1 格 |
| `< 3.70 V` | 只显示外框 |

百分比沿用旧程序的线性区间：3.50 V 为 0%，4.20 V 为 100%，并限制在 0～100%。百分比用于后续蓝牙上报或调试，LCD 当前只显示格数。

低电量进入阈值为 3.50 V，恢复阈值为 3.60 V。进入和恢复都必须连续确认 3 次有效测量：

- 防止负载开启瞬间误报低电；
- 防止电压在阈值附近来回跳变；
- 确认低电后，整个电池图标按 500 ms 周期闪烁。

需求书只要求“电量不足闪烁”，没有明确要求低电自动关机，因此当前实现不会仅凭电压自动关机。

## 5. 调度和异常处理

- 电池任务由 `Sensor_Task100ms()` 每 100 ms 调用。
- 一轮测量完成后空闲 8 个任务周期，再打开检测电路；加上 100 ms 稳定时间，约每秒得到一笔新数据。
- 仅在 READY、治疗和压力模式采样；关机、充电和故障状态立即关闭 `BATEN` 和 ADC。
- ADC 就绪、校准和单次转换均有超时，不允许异常时卡死主循环。
- 采样失败后保留上一笔有效显示，关闭 ADC，约 1 秒后重新初始化并重试。
- 合理电压范围暂定为 2.50～5.00 V，超出范围的数据不进入滤波器。

## 6. 对外读取接口

```c
uint8_t AppBattery_IsValid(void);
uint16_t AppBattery_GetVoltageMv(void);
uint8_t AppBattery_GetPercent(void);
```

调用者应先检查 `AppBattery_IsValid()`。电压单位为 mV，百分比范围为 0～100。

## 7. 量产校准建议

当前公式采用旧固件给出的 2 倍分压系数。如果实际电阻不是严格 1:1，可把 `BATTERY_DIVIDER_GAIN` 改成分子/分母形式，或增加量产校准系数。建议在 3.5 V、3.8 V、4.2 V 三个电压点与万用表对比，再决定是否调整阈值和比例。
