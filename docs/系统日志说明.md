# QW-316 系统日志说明

## 1. 输出通道

系统日志通过 SEGGER RTT 的上行通道 0 输出，不占用 USART2，不影响后续蓝牙通信。RTT 缓冲区采用非阻塞模式，主机没有及时读取时会丢弃本次输出，而不会卡住治疗和 UI 主循环。

在 J-Link RTT Viewer 或 Keil 的 J-Link RTT 窗口中连接目标芯片，选择通道 0 即可查看。通常可使用自动搜索 RTT Control Block；如果自动搜索失败，可从 map 文件中查找 `_SEGGER_RTT` 地址后手动填写。

## 2. 日志格式

```text
[I/SYS] t=1234 state POWER_OFF -> BOOTING
[I/SYS] t=3456 power ch1=10 ch2=0
[I/SYS] t=4567 battery ready, bat_adc=2500 ref_adc=3050 mv=4098 percent=85 level=2
[W/SYS] t=12000 low battery, mv=3490
[E/SYS] t=15000 battery ADC conversion failed
```

- `I`：正常系统流程和状态变化。
- `W`：可恢复的异常或需要注意的状态。
- `E`：ADC 初始化、转换等明确故障。
- `t`：系统启动后的毫秒计数。
- `SYS`：本文件设置的日志标签。

## 3. 当前关键日志

- 系统时钟、SysTick 初始化和主循环启动。
- 应用状态切换：关机、启动、治疗、压力、充电、故障。
- 按键/充电器事件和事件队列溢出。
- 治疗时间、处方、通道选择和双通道强度变化。
- 压力充气、放气和最终测量结果。
- BLE 连接状态变化。
- 电池 ADC 初始化、首次有效值、电量格变化、低电进入/恢复和采样异常恢复。
- 疗程倒计时结束以及强度、输出归零。

日志不放在 SysTick、中断波形、每次按键扫描或每次 UI 刷新中，避免高频输出影响实时性。

## 4. 调整日志级别

日志配置位于 `src/main.c` 顶部：

```c
#define DBG_TAG "SYS"
#define DBG_LVL DBG_INFO
#include "log_printf.h"
```

可选择：

```c
DBG_ERROR
DBG_WARNING
DBG_INFO
DBG_LOG
```

当前使用 `DBG_INFO`。改为 `DBG_LOG` 后会额外输出每次电池采样的原始 ADC、毫伏值和百分比，适合校准阶段；正常运行建议保持 `DBG_INFO`，避免日志过多。
