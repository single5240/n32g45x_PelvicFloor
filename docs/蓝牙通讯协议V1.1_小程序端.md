# 盆底治疗仪蓝牙通讯协议 V1.1（小程序端）

## 1. 使用说明

本文为小程序开发使用的独立协议说明。蓝牙模块与设备之间为透明串口，串口参数为 **115200，8 数据位，1 停止位，无校验、无流控**。

- 协议版本固定为 `0x11`。
- 设备连接后，小程序发送的合法协议帧默认可控制设备。
- 所有多字节整数使用**小端序**。
- 链路心跳周期为 1 s；设备连续 3 s 未收到有效心跳时停止危险输出。

## 2. 帧格式

```text
Byte 0..1  Byte 2  Byte 3  Byte 4  Byte 5..(4+LEN)  最后 1 字节
5A A5      VER     LEN     CMD     DATA[LEN]         CRC8
```

总帧长为 `6 + LEN` 字节；当 `LEN=0` 时不包含 DATA 字段。


| 字段  | 长度 | 说明                                       |
| ----- | ---: | ------------------------------------------ |
| FRAME |    2 | 固定`5A A5`                                |
| VER   |    1 | 固定`11`                                   |
| LEN   |    1 | DATA 字节数，范围`0..32`；不含 CMD 和 CRC8 |
| CMD   |    1 | 命令码                                     |
| DATA  |    N | 命令数据                                   |
| CRC8  |    1 | CRC-8/ATM，覆盖从`5A` 到 DATA 最后一个字节 |

协议采用串行请求/响应方式，同一时刻最多允许一条请求等待响应。主动通知通过独立命令码区分。

## 3. CRC-8/ATM


| 参数          | 值                                                |
| ------------- | ------------------------------------------------- |
| 多项式        | `0x07`                                            |
| 初值          | `0x00`                                            |
| 输入/输出反射 | 否                                                |
| 结果异或值    | `0x00`                                            |
| 计算范围      | `FRAME + VER + LEN + CMD + DATA`，不含 CRC8 |

查表计算公式：

```text
crc = 0x00
for each byte b in data:
    crc = table[(crc XOR (b AND 0xFF)) AND 0xFF]
```

## 4. 请求与响应

设备收到每个合法请求后，应在 200 ms 内回应。设备统一使用 `CMD=E0` 响应：

```text
响应 DATA = REQ_CMD(1) + RESULT(1) + RESPONSE_DATA(N)
```

例如，查询状态成功响应的帧结构为：

```text
5A A5 11 0F E0 71 00 [13 字节状态快照] CRC8
```

请求超时后允许重发完全相同的原帧，最多重试 2 次。所有设置和控制命令必须按幂等规则处理，重发不得重新开始倒计时或延长气路动作超时。

- CRC、版本或长度错误：设备不响应。
- 未知命令：设备响应 `UNSUPPORTED`。
- 重复设置命令：覆盖为相同目标值并返回当前结果。
- 重复启动、充气或放气命令：动作已经处于对应状态时返回 `OK`，不得重新开始计时。

### 4.1 结果码


| 值   | 名称           | 含义                       |
| ---- | -------------- | -------------------------- |
| `00` | OK             | 操作成功或请求已受理       |
| `01` | BAD_LENGTH     | DATA 长度错误              |
| `02` | BAD_PARAMETER  | 参数范围或枚举值错误       |
| `03` | UNSUPPORTED    | 当前固件不支持该命令       |
| `04` | STATE_CONFLICT | 当前设备状态不允许执行     |
| `05` | CHARGING_LOCK  | 充电互锁，禁止执行危险操作 |
| `06` | SAFETY_LOCK    | 设备安全条件不满足         |
| `08` | BUSY           | 设备正在处理不可并行的动作 |
| `09` | INTERNAL_ERROR | 设备内部错误               |

## 5. 命令定义


| CMD  | 名称                  | 请求 DATA                            | 设备限制                                             |
| ---- | --------------------- | ------------------------------------ | ---------------------------------------------------- |
| `01` | SET_TIME              | `minutes:u8`，仅 `10/20/30`          | 治疗和气路动作均已停止                               |
| `02` | SET_WORK_MODE         | `mode:u8`：`0=治疗`，`1=压力检测`    | 治疗和气路动作均已停止                               |
| `03` | SET_CH1_LEVEL         | `level:u8`，范围 `0..60`             | 治疗模式、未充电、无故障；只设置，不启动             |
| `04` | SET_CH2_LEVEL         | `level:u8`，范围 `0..60`             | 治疗模式、未充电、无故障；只设置，不启动             |
| `05` | SET_TREATMENT_PROFILE | `profile:u8`：`0=P1`，`1=P2`，`2=P3` | 治疗和气路动作均已停止                               |
| `06` | PRESSURE_INFLATE      | 空                                   | 压力检测模式、未充电、无故障                         |
| `07` | PRESSURE_DEFLATE      | 空                                   | 压力检测模式、未充电、无故障                         |
| `08` | STOP_ALL              | 空                                   | 任意状态允许；治疗输出和气泵关闭，气阀进入安全泄压状态 |
| `09` | START_THERAPY         | 空                                   | 治疗模式、时间非零、至少一路强度非零、未充电、无故障 |
| `71` | GET_STATUS            | 空                                   | 任意状态允许                                         |
| `90` | LINK_KEEPALIVE        | 空                                   | 每 1 s 发送一次                                      |

> 设置强度后，必须另发 `START_THERAPY` 才会请求开始治疗。强度为 0 时仅清零对应通道目标值。

### 5.1 主动通知


| CMD  | 名称            | 说明                                         |
| ---- | --------------- | -------------------------------------------- |
| `91` | STATUS_NOTIFY   | 状态变化时发送；稳定连接期间最多每秒发送一次 |
| `92` | PRESSURE_NOTIFY | 压力测量/压力动作变化时发送，发送频率不超过 5 Hz |

通知帧无须回应。

## 6. 状态数据

`GET_STATUS` 成功响应的 `RESPONSE_DATA` 与 `STATUS_NOTIFY` 的 DATA 均为下表 13 字节状态快照：


| 偏移 | 长度 | 字段              | 定义                                                                              |
| ---: | ---: | ----------------- | --------------------------------------------------------------------------------- |
|    0 |    1 | device_state      | `0=关机`，`1=启动中`，`2=就绪`，`3=治疗`，`4=压力`，`5=充电`，`6=故障`                       |
|    1 |    1 | profile           | `0=P1`，`1=P2`，`2=P3`                                                                       |
|    2 |    1 | ch1_level         | `0..60`                                                                                      |
|    3 |    1 | ch2_level         | `0..60`                                                                                      |
|    4 |    1 | remaining_minutes | `0..30`                                                                                      |
|    5 |    1 | remaining_seconds | `0..59`                                                                                      |
|    6 |    1 | pressure_action   | `0=空闲`，`1=充气`，`2=放气`                                                                 |
|    7 |    2 | pressure_value    | `u16` 小端序，单位 `1 mmHg/LSB`；`FFFF=无效`，仅当 flags 的 bit5=1 时有效          |
|    9 |    1 | battery_percent   | `0..100`，`FF=无效`                                                                          |
|   10 |    1 | flags             | bit0=充电接入，bit1=充满，bit2=链路心跳有效，bit3=CH1输出，bit4=CH2输出，bit5=压力有效，bit6..7=保留0 |
|   11 |    2 | fault_code        | `u16` 小端序，`0000=无故障`                                                                  |

`PRESSURE_NOTIFY` 的 DATA：

```text
pressure_value:u16(小端) + pressure_action:u8 + valid:u8 + fault_code:u16(小端)
```

压力值单位固定为 `1 mmHg/LSB`。当压力数据无效时，`pressure_value=FFFF`、`valid=0`，状态快照 flags 的 bit5 同时为 0。

### 6.1 故障码

| 值 | 含义 |
| --- | --- |
| `0000` | 无故障 |
| `0001` | 压力超限 |
| `0002` | 压力传感器或 ADC 数据无效 |
| `0003` | 充气超时 |
| `0004` | 电池数据无效 |
| `0005` | 低电量禁止工作 |
| `0006` | 治疗输出未标定或安全条件不满足 |
| `0007` | 内部状态异常 |

## 7. 设备端通讯行为

1. 设备收到 `GET_STATUS` 后返回当前完整状态快照。
2. 设备收到 `LINK_KEEPALIVE` 后更新最近有效心跳时间并返回响应。
3. 设备收到设置或控制命令后，先检查帧、参数和当前安全状态，再返回对应结果码；未通过检查的命令不得改变设备状态或输出。
4. 异步动作命令被受理后，设备先返回 `OK`；动作状态改变时再发送 `STATUS_NOTIFY` 或 `PRESSURE_NOTIFY`。
5. 远程启动治疗、充气或放气后启用心跳监控；设备连续 3 s 未收到有效心跳、检测到蓝牙断链或进入故障状态时，停止远程启动的危险输出，并在链路仍可发送时上报最新状态。未启动远程危险动作时，心跳超时不得影响本地操作。
6. 本地按键、充电状态或故障引起设备状态变化时，设备发送 `STATUS_NOTIFY`；压力数值或压力动作变化时发送 `PRESSURE_NOTIFY`。

## 8. 联调报文示例

### 查询状态

```text
请求：5A A5 11 00 71 0F
```

### 设置疗程为 30 分钟

```text
请求：5A A5 11 01 01 1E BE
       |  |  |  |  |  |  └─ CRC8
       |  |  |  |  |  └──── DATA=30
       |  |  |  |  └─────── CMD=SET_TIME
       |  |  |  └────────── LEN=01
       └──┴──┴───────────── 固定帧头和版本
```

### 请求开始治疗

```text
请求：5A A5 11 00 09 60
```

### 查询状态成功响应示例

示例状态：治疗模式、P2、CH1=10、CH2=0、剩余 20:00、压力空闲、电池 80%、链路有效且 CH1 输出使能、无故障。

```text
5A A5 11 0F E0 71 00 03 01 0A 00 14 00 00 00 00 50 0C 00 00 1B
```

其中 `LEN=0F`（15 字节 DATA）；最后 `1B` 为 CRC8。

## 9. BLE 承载参数（待确认）

以下参数属于蓝牙模块配置，不得从本应用协议中推测；提供模块资料后再补充：

- Service UUID；
- 写特征 UUID；
- Notify 特征 UUID；
- 写入方式（Write 或 Write Without Response）；
- ATT MTU 和单次有效载荷上限；
- 设备名称或广播过滤规则。

BLE 写入或通知可能拆分一帧，也可能一次携带多帧。接收方必须使用缓存按帧头和 `LEN` 组帧，不能假设一次 BLE 回调就是一帧。
