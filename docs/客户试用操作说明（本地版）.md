# 盆底治疗仪客户试用操作说明（本地按键版）

> **适用范围：** 本说明仅适用于当前试用固件和已完成内部台架确认的试用样机

## 1. 注意事项

1. **禁止边充电边进行治疗或气囊压力操作。** 使用前请拔下充电器。
2. 小程序控制进入评估模式、治疗模式等会让失效本地按键。

## 2. 按键与显示


| 按键        | 标识/作用            | 基本操作                                                                                    |
| ----------- | -------------------- | ------------------------------------------------------------------------------------------- |
| 电源键      | 开机、关机、设置时长 | 长按约 3 秒开机或关机；在工作页短按切换时长。                                               |
| 功能键      | 治疗页/压力页切换    | 短按切换页面；切换时当前治疗输出或气泵动作会停止。                                          |
| 启动/停止键 | 模式、通道、压力流程 | 治疗页短按切换 P1/P2/P3，长按约 2 秒切换 CH1/CH2；压力页短按控制流程，长按约 3 秒请求放气。 |
| 加键        | 增加强度             | 治疗页中将当前选中通道加 1 档。                                                             |
| 减键        | 降低强度             | 治疗页中将当前选中通道减 1 档。                                                             |

设备对正常有效操作有蜂鸣提示；开机和关机请求通常为三声提示。按住达到长按时间即可松开，无需持续按住。

## 3. 开机、关机与充电

### 3.1 开机

1. 确认已拔下充电器，配套附件连接完好，且现场具备项目方规定的试用和监护条件。
2. 长按电源键约 3 秒，等待开机提示和屏幕显示。
3. 开机后默认进入治疗页，默认疗程设置为 30 分钟，CH1/CH2 强度均为 0。
4. 若电量过低，设备会拒绝进入工作状态并显示低电提示。请停止试用并使用项目方提供的充电器充电。

### 3.2 设置疗程时间

在治疗页或压力页短按电源键，时长按以下顺序循环：

`30 分钟 → 10 分钟 → 20 分钟 → 30 分钟`

治疗倒计时仅在治疗页、且至少一个通道强度大于 0 时递减。将两个通道都调为 0，输出暂停，倒计时不继续减少。

### 3.3 关机

1. 先将两个治疗通道强度调至 0；若正在进行压力流程，先停止并按项目方要求完成放气。
2. 长按电源键约 3 秒，听到关机提示后松开。
3. 确认屏幕熄灭或进入充电显示后，再收纳设备和附件。

设备在低电、模式切换、疗程结束或关机时会请求停止危险输出；但试用人员仍应以屏幕状态、附件状态和现场监护为准，不得仅依赖软件提示。

### 3.4 充电

1. 先关机，使用项目方随设备提供并确认匹配的充电器和线缆。
2. 接入充电器后，设备进入充电显示；充满后显示状态以实际样机为准。
3. 充电期间不进行治疗、加减强度或压力气囊操作；如需试用，先拔下充电器并重新确认设备状态。
4. 充电异常、外壳/充电器发热、异味、冒烟、液体渗入或电池鼓胀时，立即断开电源并停止使用。

## 4. 治疗页操作

### 4.1 开始前检查

1. 确认屏幕处于治疗页，充电器已拔下。
2. 确认已按经批准的试用方案安装配套附件；未明确附件型号、连接位置或使用对象时，不得自行尝试。
3. 确认 CH1 和 CH2 当前强度均为 0，再选择本次需要的模式、通道和疗程时间。

### 4.2 选择模式

在治疗页短按启动/停止键，在 `P1 → P2 → P3 → P1` 间循环选择。

每次切换模式时，设备会停止当前治疗输出，并将 CH1、CH2 强度清零。因此，切换模式后必须重新从低强度开始设置；不得在有输出时凭感觉连续切换模式。

### 4.3 选择与调节通道

1. 在治疗页长按启动/停止键约 2 秒，在 CH1 和 CH2 间切换当前选中通道；以屏幕通道指示为准。
2. 短按加键或减键，每次将当前选中通道调整 1 档，范围为 0～60。
3. 首次启动或重新启用通道时，必须从 0 档开始逐级增加；每次加档后停留观察，出现任何不适立即短按减键降档，直至 0 档。
4. 如需使用另一通道，先将当前通道降至 0，再长按启动/停止键选中另一通道后调节。两通道是否可同时用于人体试用，必须由项目方的批准方案明确；未明确时仅使用一个通道。

> 注意：治疗页的“启动/停止”短按键用于切换 P1～P3，并非开始输出键。未连接小程序，本地控制时，治疗输出由所选通道的强度从 0 调至非零后启动。

### 4.4 结束治疗

以下任一方式都应视为本次治疗结束：

- 逐次按减键，使已使用通道回到 0；
- 短按启动/停止键切换模式（会停止输出并清零强度）；
- 短按功能键进入压力页（会停止治疗输出）；
- 倒计时结束（强度及输出自动清零）；
- 长按电源键关机。

治疗结束时，如果已经连接小程序，治疗信息将自动发送。
治疗结束后，确认屏幕上 CH1/CH2 强度均为 0，再取下附件。不要在强度非零时拔插附件或接触导电部位。

## 5. 压力页操作

1. 在治疗页确认 CH1/CH2 都为 0；短按功能键进入压力页。切换会停止治疗输出。
2. 确认充电器已拔下、气囊和管路连接正确且无折叠、泄漏或挤压。
3. 压力页空闲时短按启动/停止键，设备开始预充气。本地的预充气目标为 **36 mmHg**，最长预充气时间为 **60 秒**。
4. 达到目标后，设备进入等待状态；再次短按启动/停止键，本地开始最长 **1800 秒（30 分钟）** 的评估会话。屏幕显示实时压力并记录本轮最大值。
5. 预充气过程中短按启动/停止键会停止并取消本轮。
6. 评估中短按会结束本轮评估，结束评估后，压力值会固定显示评估流程的平均值，直到放气或者切换模式。
7. 需要放气时，长按启动/停止键约 3 秒。设备停止气泵并执行约 3 秒放气流程；待流程结束、气囊确认无压后再拆卸。
8. 达到软件上限、预充气超时、传感器采样异常或切换页面时，设备会停止当前压力流程。
