# QW-316 UI 操作逻辑

本文档以《手持盆底治疗仪需求书.xlsx》为需求基线，记录新 `main()` 中已经实现的 UI 行为，以及需要由后续业务模块接入的接口。

## 1. 系统状态

| 状态 | UI 行为 | 输出要求 |
| --- | --- | --- |
| 关机 | LCD 和背光关闭，只扫描开机键及充电状态 | 电疗、DAC、气泵和电磁阀全部关闭 |
| 启动 | 初始化 LCD 和蜂鸣器，响三声 | 保持危险输出关闭 |
| 治疗模式 | 显示双通道强度、处方 P1～P3、时间、蓝牙和电池 | 两路目标强度独立 |
| 检测模式 | 显示压力、充气/放气、时间、蓝牙和电池 | 由压力控制模块执行气泵和电磁阀动作 |
| 仅充电显示 | 关机插电时显示电池动画，长按开关机键可进入正常工作 | 正常工作后允许边充电边使用 |
| 故障 | 清空工作显示并保持背光 | 所有危险输出立即归零 |

模式切换、倒计时结束、关机及进入故障状态时，治疗档位和硬件输出必须立即归零；工作中插入或拔出充电器不打断当前功能。

## 2. 按键判定

- 每 10 ms 扫描一次按键，连续稳定 30 ms 后确认电平变化。
- 短按在按键稳定释放时产生，长按释放后不会补发短按。
- 开关机键在关机和开机状态下均长按 2 秒生效。
- 启动/停止键长按 2 秒生效。
- UI 开启期间背光保持常亮，UI 关闭时背光同步关闭，不再单独按无操作时间熄灭。

## 3. 按键映射

| 按键 | 操作 | 当前行为 |
| --- | --- | --- |
| 开关机键 | 关机或仅充电显示时长按 2 秒 | 开机、LCD 点亮、默认进入治疗模式，蜂鸣器响三声 |
| 开关机键 | 开机时长按 2 秒 | 所有输出和档位归零；接着充电器时回到仅充电显示，否则关闭 LCD |
| 开关机键 | 短按 | 时间按 30 → 10 → 20 → 30 分钟循环，时间图标保持常亮 |
| 功能键 | 短按 | 治疗/检测模式切换；切换时强制当前输出归零 |
| 启动/停止键 | 治疗模式短按 | P1 → P2 → P3 → P1，切换时双通道档位归零 |
| 启动/停止键 | 治疗模式长按 2 秒 | 在通道 1 和通道 2 之间切换选择 |
| 启动/停止键 | 检测模式短按 | 充气启动/停止，充气期间充气图标闪烁 |
| 启动/停止键 | 检测模式长按 2 秒 | 请求放气，放气图标闪烁；当前 UI 临时时序为 2 秒 |
| “+”键 | 治疗模式短按 | 选中通道强度加 1，最大 60 |
| “-”键 | 治疗模式短按 | 选中通道强度减 1，最小 0 |

除开关机三声外，其他有效按键操作蜂鸣器响一声。仅充电显示状态下只有开关机键长按有效；进入治疗或检测模式后，充电不会屏蔽任何按键。

## 4. LCD 显示

### 4.1 治疗模式

- 显示通道 1 强度、P1～P3、通道 2 强度和剩余分钟。
- 压力数值区域消隐。
- 当前选中通道图标每 500 ms 闪烁。
- 模式图标每 500 ms 闪烁。
- 时间数值和 `min` 图标始终保持常亮，不参与闪烁。

### 4.2 检测模式

- 双通道强度及 P 模式区域消隐。
- 充气期间充气图标闪烁，充气完成后停止闪烁。
- 放气期间放气图标闪烁。
- 压力模块提交最终结果后，压力数值及压力图标持续闪烁。
- 压力结果闪烁期间再次按下任意有效按键，停止结果闪烁。

### 4.3 公共图标

- 蓝牙未连接：蓝牙图标常亮。
- 蓝牙连接成功：蓝牙图标每 500 ms 闪烁。
- 低电量：整个电池图标每 500 ms 闪烁。
- 充电中：无论处于仅充电显示、治疗或检测模式，电池格数都每秒按空、一格、两格、三格循环。
- 仅充电显示状态仍周期启动电池 ADC，计算电压和估算电量；进入工作模式后沿用同一采样会话，真正关机时才关闭 ADC。
- 充满电：满格电池保持常亮。

## 5. 时间行为

- 默认治疗时间为 30 分钟，可设置为 10、20 或 30 分钟。
- 任一治疗通道强度非零时开始按秒倒计时。
- LCD 分钟采用向上取整显示，例如剩余 9:59～9:01 显示 10，剩余时间到 9:00 后才显示 9。
- 倒计时结束时双通道档位及所有治疗硬件输出立即归零。
- 倒计时结束后时间保持显示 0，不自动恢复为设置值。
- 疗程结束后第一次按“+”增加强度时，重新装载上一次设置的疗程时间并开始新疗程；也可以先按时间键重新选择 10、20 或 30 分钟。

## 6. UI 对外接口

以下接口由后续蓝牙、电池和压力模块在主循环上下文中调用：

| 接口 | 用途 |
| --- | --- |
| `AppUi_SetBleConnected()` | 更新蓝牙连接图标 |
| `AppUi_SetBattery()` | 更新电池格数及低电量状态 |
| `AppUi_InflationCompleted()` | 通知 UI 充气已经完成 |
| `AppUi_SetPressureResult()` | 提交最终压力结果并开始持续闪烁 |

实体按键已经通过事件队列进入状态机；蓝牙协议后续必须转换成相同事件，不允许直接修改 UI 或业务全局变量。

## 7. 需求中需要确认的歧义

1. 功能说明要求压力区间计算“平均值”，按键说明要求显示“最高值”。当前 UI 只接收最终结果，统计方法需在压力算法实现前确认。
2. “+”键文字描述写成“减小强度”，但按键名称、60 档上限说明及面板图均表示增加；当前按增加实现。
3. 第三种电疗模式在一处写成“模式三 P2”，结合“三种模式”和液晶图，当前按 P1、P2、P3 实现。
4. 需求书原定放气长按 3 秒触发，现按实机操作手感调整为 2 秒；电磁阀保持时间仍未明确，当前 UI 暂沿用旧固件的 2 秒提示时序，最终以气路验证结果为准。

## 8. 实体按键位置

1. 中：开关机/时间键。
2. 左：功能键。
3. 右：启动/停止及通道选择键。
4. 上：“+”键。
5. 下：“-”键。
